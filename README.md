# FinLab — Finance Education Platform

Finance education built for people who are serious.

The same analytical frameworks used by senior analysts at top banks, PE firms, and credit funds — taught from first principles, with real examples and live models.

## What's Inside
- 13-lesson learning path (Financial Statements → Valuation → Deals → Advanced)
- Live DCF calculator with sensitivity heatmap
- Live LBO return calculator with deal verdict
- 3 full deal room cases (sell-side M&A, PE buyout, merger)
- 26-term searchable finance glossary
- XP and progress tracking system
